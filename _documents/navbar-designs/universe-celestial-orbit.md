# Concept 8: Universe Celestial Orbit Menu

An interactive astronomical solar system menu where links are planetary nodes orbiting a central solar core. Clicking the core expands or collapses concentric orbit paths in a gravity wave effect.

## Design Aesthetic
* **Sacred Geometry & Space**: Fits deep cosmic/universe mechanics themes.
* **Spin-Locked Nodes**: Children node elements rotate along concentric dotted rings, but counter-rotate individually to keep symbols standing upright.
* **Supernova Core**: Central Sun node glows with aura rings and solar pulses.

## Library Stack Integration
* **`lucide-react`**: For planetary vector symbols.
* **`Tailwind CSS`**: Hardware-accelerated CSS Keyframe animations for real-time 60fps orbit loops.
* **`React hooks`**: Simple states to trigger concentric radial delays on expansion.
