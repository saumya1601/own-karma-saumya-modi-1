# Loading Screen Designs

Design concepts and documentation for loading screen components.

## Color Palette

All loading screens follow the project color system defined in [color-palette.md](../color-palette.md):

- **Deep Obsidian Black**: `bg-slate-950` / `#020617`
- **Alabaster White**: `text-slate-200` / `#E2E8F0`
- **Molten Gold**: `text-amber-400` / `#D4AF37`

## Components

Loading screen components are located in `src/components/` with the `Loading` prefix.
